A single-line joke about office life, written for the
[One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162)
bounty on make.fun.

Running `main.ts` (Node 22) writes the joke to `entry.txt` in the output
directory: `MAKEFUN_OUTPUT_DIR` when set, otherwise `/output`, otherwise
`./out`. The output is deterministic — the same bytes on every run.

## The joke

> The fire drill is the only meeting where everyone arrives on time, leaves
> together, and nobody asks for the slides.
